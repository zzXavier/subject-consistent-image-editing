The [IP-Adapter author repository](https://github.com/tencent-ailab/IP-Adapter/tree/62e4af9d0c1ac7d5f8dd386a0ccf2211346af1a2) supplies the reference-conditioning design and Apache-2.0 code. This project calls Diffusers 0.31.0's IP-Adapter loader using [the pinned authors' SD1.5 image adapter and vision encoder](https://huggingface.co/h94/IP-Adapter/tree/018e402774aeeddd60609b4ecdb7e298259dc729). The regional arm uses the upstream mask-aware attention processor.

All arms use [the same pretrained Stable Diffusion 1.5 checkpoint](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5/tree/451f4fe16113bff5a5d2269ed5ad43b0592e9a14) and the four-channel latent-blending path in the [pinned Diffusers inpainting pipeline](https://github.com/huggingface/diffusers/blob/v0.31.0/src/diffusers/pipelines/stable_diffusion/pipeline_stable_diffusion_inpaint.py). Component identities and content hashes are frozen in `configs/sd15-files.json` and `configs/ip-files.json`. `P07_SD15_ROOT` and `P07_IP_ROOT` can point at existing copies of those exact snapshots.

The new work is the product-level split, mask generation, matched three-arm protocol, frozen-color edit requests, independent foreground-color gallery retrieval, hue/foreground checks and per-case outputs. See [data and attribution](data.md) for the catalog inputs and the CC BY 4.0 terms.

`author_demo.py` invokes the original `ip_adapter.IPAdapter.generate` from a clean checkout at the Git pin above. It follows the authors' [image prompt notebook](https://github.com/tencent-ailab/IP-Adapter/blob/62e4af9d0c1ac7d5f8dd386a0ccf2211346af1a2/ip_adapter_demo.ipynb) with its DDIM schedule. This local demonstration uses the base checkpoint's bundled VAE, the authors' safetensors adapter, one ABO reference, 384 px and 12 steps. A separate foreground mask is used only in the main paired editing experiment.
